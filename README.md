# 苳苳的小兔｜使用说明

这是一个完全离线的静态网页养宠小程序。它使用项目目录中的 `1.jpg`–`6.jpg` 显示小兔的不同表情，所有养成进度、待办和烦恼记录都只保存在使用者自己的浏览器中。

## 一、运行要求

- Windows 10 或 Windows 11
- Edge、Chrome 等现代浏览器
- 不需要安装 Godot、Node、Python
- 不需要连接网络

请保留整个项目文件夹，不要只复制启动脚本或 `index.html`。

## 二、启动小程序

### 推荐方式

1. 双击 `启动兔老大.cmd`。
2. CMD 黑色窗口会显示小程序的本机网址。
3. 默认浏览器会自动打开网页。
4. 小兔会自动跑到礼盒旁拆开礼物。
5. 礼物中显示“苳苳的小兔”后，自动进入养宠页面。

启动动画右上角有“跳过”按钮。

启动器会自动寻找并记住一个可用的本机端口，不需要手动设置端口。

### 直接打开

也可以直接双击 `index.html`。主要养宠功能可以使用，但浏览器可能限制离线缓存和安装为桌面小程序等功能，因此更推荐使用 CMD 启动。

## 三、关闭小程序

1. 关闭浏览器中的游戏标签页。
2. 关闭标题为 `Rabbit Pet Local Server` 的 CMD 黑色窗口。

只有关闭 CMD 窗口，本地网页服务和端口才会停止。关闭前养成进度会自动保存。

## 四、养宠操作

主页面右侧提供以下互动：

- **喂食**：消耗少量胡萝卜币，增加饱食和心情。
- **摸摸**：增加心情、亲密度和少量胡萝卜币。
- **玩耍**：增加心情和亲密度，同时消耗精力。
- **睡觉**：让小兔休息并恢复精力，再次点击可以叫醒。
- **倾听烦恼**：记录想对小兔说的话。

也可以直接点击页面中央的小兔进行“摸摸”互动。

饱食、心情和精力会随真实时间缓慢变化。关闭页面后最多计算 8 小时的离线变化，小兔不会死亡或永久离开。

## 五、等级、货币与装扮

- 互动可以获得经验和胡萝卜币。
- 经验达到要求后会提升亲密等级。
- 每天可以领取一次“每日礼物”。
- 胡萝卜币可以解锁墨镜、皇冠等装扮。
- 已解锁的装扮会自动保存。

## 六、倾听烦恼

1. 点击互动区域中的“倾听烦恼”。
2. 在输入框中写下想说的话。
3. 点击“交给小兔保管”。
4. 小兔会给出一句暖心回应。

烦恼记录显示在“心事小抽屉”中，可以查看记录时间，也可以点击右上角的 `×` 删除单条记录。

烦恼只保存在当前电脑和当前浏览器中：

- 不会上传到网络。
- 不会与其他电脑同步。
- “归零养成进度”不会删除烦恼。
- 清除浏览器站点数据会删除烦恼记录。

## 七、工作模式

在养宠页面按 `Esc`，或点击右上角“工作模式”，可以立即：

- 暂停游戏画面。
- 保存养成进度。
- 切换到普通工作待办页面。

在工作页面再次按 `Esc` 即可返回养宠页面。工作待办会单独保存在当前浏览器中。

## 八、自动保存与备份

小程序会在以下情况自动保存：

- 完成互动后
- 切换到后台时
- 进入工作模式时
- 每隔约 30 秒
- 关闭页面前

### 导出存档

点击“导出存档”，浏览器会下载一个 `.json` 文件。建议在清理浏览器数据、重装系统或更换电脑前进行备份。

### 导入存档

点击“导入存档”，选择以前导出的 `.json` 文件，即可恢复养成进度。

导出和导入的养成存档不包含烦恼记录与工作待办。

## 九、归零养成进度

1. 在左侧状态卡片底部点击“归零养成进度”。
2. 阅读确认提示。
3. 点击确定。

归零后，等级、状态、胡萝卜币、装扮和每日礼物记录会恢复初始值。

烦恼记录和工作待办不会被删除。

## 十、发送给其他人

1. 关闭正在运行的小程序。
2. 将整个项目文件夹压缩为 ZIP。
3. 把 ZIP 文件发送给对方。
4. 对方解压后双击 `启动兔老大.cmd`。

每个人拥有独立的本机存档，互相不会同步。不要只发送 CMD 文件，图片、HTML、CSS、JavaScript 和启动脚本必须放在一起。

## 十一、常见问题

### 双击 CMD 后没有自动打开网页

查看 CMD 窗口中显示的网址，例如：

```text
http://127.0.0.1:27531/
```

复制该网址，粘贴到 Edge 或 Chrome 地址栏中打开。

### 提示端口被占用或没有权限

新版启动器会自动尝试其他端口并记住可用端口。关闭旧的 `Rabbit Pet Local Server` 窗口后，再重新双击启动脚本。

### 页面没有显示最新功能

按 `Ctrl + F5` 强制刷新页面。更新离线缓存后，重新打开即可看到最新版本。

### 如何彻底停止端口

关闭 `Rabbit Pet Local Server` CMD 窗口。只关闭浏览器标签页不会停止本地端口。

### 进度突然消失

常见原因包括：

- 清除了浏览器站点数据。
- 换用了另一个浏览器。
- 使用隐私或无痕模式运行。
- 手动删除了浏览器本地数据。

可以通过以前导出的 JSON 存档恢复养成进度。

## 十二、隐私说明

- 小程序没有账号系统。
- 不会连接云端数据库。
- 不会上传养成数据、烦恼或待办。
- 数据由浏览器的本地存储功能保存。
