# 兔老大的摸鱼小窝

这是一个完全离线的静态网页养宠小程序，直接使用目录中的 `1.jpg`–`6.jpg` 作为宠物表情素材。

## 启动

双击 `启动兔老大.cmd`。启动器会自动选择并记住一个可用的本机端口，然后打开浏览器；关闭命令窗口即可停止。

也可以直接双击 `index.html`，但通过启动脚本打开时，离线缓存和 PWA 功能更完整。

## 功能

- 喂食、摸摸、玩耍、睡觉和真实时间状态变化
- 胡萝卜币、等级、亲密度与装扮解锁
- 每日礼物、30 秒自动保存、离线进度（最多 8 小时）
- `Esc` 一键切换工作待办页并静音
- 本机存档导出与导入
- 断网后仍可运行

存档仅位于当前浏览器的 `localStorage`，不会联网或上传。清除浏览器站点数据前，请先点击“导出存档”。
